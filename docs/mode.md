📄 Mode Ops
- — tmdgFiles
- Version : v1.0.0

Le Mode Ops est une vue compacte inspirée des gestionnaires de fichiers en terminal comme ranger.

🎯 Objectif
Offrir une navigation rapide et efficace pour les utilisateurs avancés.

🔧 Caractéristiques
- Interface compacte
- Raccourcis clavier essentiels
- Affichage minimaliste
- Panneau de logs des opérations

🧱 Structure prévue
```text
Window (Ops Mode)
 ├── FileList compacte
 └── LogPanel (opérations)
```

🏁 Conclusion
Le Mode Ops apporte une approche plus technique et rapide, idéale pour les workflows avancés.
