UI Design
- — tmdgFiles
- Version : v1.0.0

L’interface de **tmdgFiles** est pensée pour rester simple, lisible et efficace.

🎯 Principes
```text
- Interface claire et minimaliste
- Navigation rapide via une barre latérale
- Liste de fichiers centrée sur l’essentiel
- Icônes légères et cohérentes
- Structure horizontale : Sidebar → FileList
```

🧱 Structure UI
```text
Window
 ├── Sidebar (Home, Documents, Téléchargements, Favoris)
 └── FileList (fichiers du dossier courant)
```

🎨 Style
- Espacement léger
- Labels simples
- Orientation horizontale
- Pas de surcharge visuelle

🏁 Objectif
Une UI légère, intuitive, extensible pour les futures versions.
