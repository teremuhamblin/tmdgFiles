🗺️ ROADMAP
>> — tmdgFiles
- Gestionnaire de fichiers moderne, rapide, modulaire, inspiré de Nemo/Nautilus mais avec une identité unique.

🎯 Objectif de la version
- Créer un gestionnaire de fichiers fonctionnel, stable, minimal mais puissant, servant de base pour les futures versions (v2, v3…).
